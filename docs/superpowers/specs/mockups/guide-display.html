가이드(시작·끝맺음 팁)는 어디에 보이면 좋을까요?

Claude Code 모드에서 "기능 개발" 단축키를 눌렀을 때 입력창에 들어가는 모습이에요. 셋 중 마음에 드는 걸 클릭해 주세요. 섞어도 돼요.

A. 빈칸 속에 예시

팁과 예시가 붙여넣는 글 안에 들어가요. 빈칸을 지우고 내 내용으로 바꿔 쓰는 방식이에요.

+ 쓰는 자리에서 바로 보여요
+ 처음 쓸 때 배우기 좋아요
− 예시를 안 지우고 보낼 수 있어요
− 붙여넣는 글이 길어져요
claude ›## 목표 ## 참고 ## 범위와 제약 - 포함: - 제외: ## 완료 조건 - - <테스트 명령> 실행 후 명령과 결과를 보고해줘
목표 쓰는 팁"무엇을 + 왜"를 한두 문장으로 써요.

끝맺음 팁"고쳐줘"처럼 요청하세요. "제안해줄래?"라고 하면 제안만 하고 끝날 수 있어요.Esc로 닫기 · 다음 팁 ⌥→

B. 깔끔한 뼈대 + 옆에 팁 카드

붙여넣는 글에는 제목과 빈칸만 들어가요. 팁은 화면 구석에 작은 카드로 잠깐 떠요.

+ 보내는 글이 깔끔해요
+ 팁이 실수로 섞이지 않아요
− 창이 하나 더 떠요
− 익숙해지면 끄고 싶을 수 있어요
claude ›## 목표 {무엇을} — 이유: {왜} ## 참고 @{따라할 파일} ## 범위와 제약 - 포함: {} - 제외: {} ## 완료 조건 - {관찰 가능한 동작} - {테스트 명령} 실행 후 명령과 결과를 보고해줘 코드 전에 계획을 먼저 보여줘

C. 짧은 빈칸 + 추천 끝맺음 미리 채움

빈칸 이름만 짧게 들어가요. 좋은 끝맺음 문장(초록색)은 미리 채워져 있어요. 자세한 팁은 앱의 편집 화면에서만 보여요.

+ 가장 짧고 빨라요
+ 좋은 습관이 기본값으로 들어가요
− 왜 그렇게 쓰는지는 따로 봐야 알아요
