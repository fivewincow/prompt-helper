# Prompt Helper 사용 가이드

Prompt Helper는 AI 코딩 에이전트(Claude Code, Codex, Gemini)에 보낼 프롬프트를 단축키로 꺼내 쓰는 메뉴바 앱이에요. 템플릿을 불러와 빈칸을 채우고, 원래 쓰던 앱의 커서 위치에 붙여넣어요.

이 문서에서 단축키는 맥 기준으로 적었어요. 윈도우에서는 ⌃⌥ 대신 `Ctrl+Alt`, ⌘ 대신 `Ctrl`을 누르면 돼요.

## 1. 처음 설정

**맥:** 앱이 대신 ⌘V를 눌러 붙여넣으려면 **손쉬운 사용** 권한이 필요해요.

1. 메뉴바의 `CC`를 클릭해요.
2. "손쉬운 사용 권한 켜기…"를 눌러요.
3. 시스템 설정 목록에서 Prompt Helper(개발 중에는 `prompt-helper`)를 켜요.
4. 5초쯤 지나 메뉴에서 그 항목이 사라지면 끝이에요.

권한이 없으면 붙여넣지 않고 클립보드에만 복사한 뒤 "⌘V로 붙여넣으세요" 알림을 띄워요.

개발 빌드는 다시 빌드할 때마다 맥이 새 앱으로 볼 수 있어요. 권한이 켜져 있는데도 붙여넣기가 안 되면, 목록에서 지웠다가 다시 추가해 주세요.

**윈도우:** 따로 설정할 권한이 없어요.

## 2. 메뉴바 메뉴

메뉴바(윈도우는 트레이)의 아이콘을 클릭하면 열려요. 맥은 현재 모드를 `CC`, `CX`, `GM`으로 보여줘요.

| 항목 | 하는 일 |
|---|---|
| 모드 | Claude Code / Codex / Gemini 중 하나를 골라요 |
| 템플릿 | 템플릿을 골라 채우기 창을 열어요 |
| 문구 | 자주 쓰는 문장을 바로 붙여넣어요 |
| 템플릿 편집… | 편집 창을 열어요 |
| 설정… | 편집 창의 "단축키 · 설정" 탭을 열어요 |
| 종료 | 앱을 끝내요 |

## 3. 모드

같은 템플릿이라도 AI마다 잘 듣는 방식이 달라서, 템플릿마다 모드별 버전이 있어요.

| 모드 | 메뉴바 표시 | 규칙 파일 |
|---|---|---|
| Claude Code | CC | CLAUDE.md |
| Codex | CX | AGENTS.md |
| Gemini | GM | GEMINI.md |

- ⌃⌥M을 누르면 다음 모드로 바뀌고, 오른쪽 위에 알림이 잠깐 떠요.
- 템플릿에 `{{rulesFile}}`이 있으면 현재 모드의 규칙 파일 이름으로 바뀌어요.
- 어떤 모드의 본문이 비어 있으면, 그 모드에서는 Claude Code 버전을 대신 넣고 알려줘요.

## 4. 기본 단축키

| 기능 | 맥 | 윈도우 |
|---|---|---|
| 기획 문서 | ⌃⌥1 | Ctrl+Alt+1 |
| 기능 개발 | ⌃⌥2 | Ctrl+Alt+2 |
| 테스트 | ⌃⌥3 | Ctrl+Alt+3 |
| 버그 수정 | ⌃⌥4 | Ctrl+Alt+4 |
| 긴 작업 · 자료 조사 | ⌃⌥5 | Ctrl+Alt+5 |
| 검색 팝업 | ⌃⌥P | Ctrl+Alt+P |
| 모드 전환 | ⌃⌥M | Ctrl+Alt+M |

모두 편집 창의 "단축키 · 설정" 탭에서 바꿀 수 있어요.

## 5. 채우기 창: 템플릿 쓰기

프롬프트를 쓸 앱(터미널, 메모장, 채팅창 등)에 커서를 둔 채 템플릿 단축키를 누르면 채우기 창이 떠요.

1. 첫 빈칸이 선택된 상태로 열려요. 바로 입력하면 빈칸이 내용으로 바뀌어요.
2. `Tab`을 누르면 다음 빈칸으로 가요(`Shift+Tab`은 이전 빈칸).
3. 다 쓰면 ⌘Enter를 눌러요. 창이 닫히고, 원래 앱의 커서 위치에 붙여넣어져요.

| 키 | 동작 |
|---|---|
| Tab / Shift+Tab | 다음 / 이전 빈칸 |
| Enter | 줄바꿈 |
| ⌘Enter | 붙여넣기. 빈칸이 남았으면 한 번 알려주고, 한 번 더 누르면 그대로 붙여넣어요 |
| ⌘K | 문구 검색. 고른 문구가 커서 위치에 들어가요 |
| ⌘R | 템플릿 원문으로 되돌리기. 쓴 내용이 있으면 먼저 물어봐요 |
| Esc | 닫기. 붙여넣지 않고 원래 앱으로 돌아가요 |

**색 표시**
- 파란색: 섹션 제목(`## 목표` 등)
- 노란색: 아직 채우지 않은 빈칸
- 초록색: 미리 넣어 둔 추천 마무리 문장

**임시저장**
- Esc로 닫거나 다른 템플릿으로 바꾸면, 쓰던 내용이 그 템플릿에 임시저장돼요.
- 같은 템플릿을 다시 열면 "임시저장된 내용을 이어서 써요"라는 안내와 함께 이어서 쓸 수 있어요.
- 처음부터 다시 쓰고 싶으면 ⌘R을 누르고 Enter를 눌러요.
- 붙여넣기에 성공하면 그 템플릿의 임시저장은 지워져요. 앱을 종료하면 모두 사라져요.

**다른 템플릿으로 바꾸기**
- 쓰는 중에 다른 템플릿 단축키를 누르면 "바꿀까요?"라고 물어요. Enter를 누르면 바꾸고(지금 내용은 임시저장돼요), Esc를 누르면 계속 써요.
- 지금 쓰고 있는 템플릿의 단축키를 다시 누르면 아무 일도 일어나지 않아요.

**클립보드**
- 붙여넣는 동안 클립보드를 잠깐 빌려 쓰고, 끝나면 원래 내용(텍스트나 이미지)을 되돌려 놓아요.

## 6. 검색 팝업 (⌃⌥P)

템플릿과 문구를 한곳에서 검색해요.

- 검색어 없이 열면 최근에 쓴 항목이 맨 위에 보여요.
- `↑` `↓`로 고르고 Enter를 누르면 넣어요. Esc나 팝업 바깥 클릭으로 닫아요.
- 문구를 고르면 바로 붙여넣어요. 템플릿을 고르면 채우기 창이 열려요.
- 한글을 조합하는 중에 누른 Enter는 조합만 끝내고, 항목을 고르지는 않아요.
- 채우기 창이 열려 있을 때 누르면, 채우기 창 안의 문구 검색(⌘K)이 열려요.

## 7. 바로 붙여넣기

설정에서 "바로 붙여넣기"를 고르면 채우기 창 없이 템플릿을 그대로 붙여넣어요. 빈칸은 붙여넣은 곳에서 직접 채워요.

다만 터미널의 Claude Code는 긴 붙여넣기를 `[Pasted text #1 +N lines]`로 접어 보여줘서, 붙여넣은 뒤에는 빈칸을 고치기 어려워요. 그래서 기본값은 채우기 창이에요.

## 8. 편집 창

메뉴의 "템플릿 편집…"으로 열어요. 탭이 세 개 있어요.

### 템플릿 탭
- 왼쪽 목록에서 템플릿을 골라요. "기본 템플릿"과 "내 템플릿"으로 나뉘어 있어요.
- 위쪽 모드 버튼(Claude Code / Codex / Gemini)으로 모드별 본문을 바꿔 가며 고쳐요. 본문이 빈 모드에는 점이 표시돼요.
- 고친 내용은 바로 저장되고, 단축키를 누르면 바로 반영돼요.
- **단축키:** 버튼을 누르고 원하는 조합을 눌러요. Esc는 취소, Backspace는 단축키 지우기예요. 다른 기능이 이미 쓰는 조합은 거절하고, 시스템이나 흔한 단축키와 겹치면 경고해요.
- **기본값으로:** 기본 템플릿의 세 모드 본문과 이름을 처음 상태로 되돌려요. 누르면 먼저 확인을 받아요.
- **다른 모드에 복사:** 지금 모드의 본문을 다른 두 모드에 덮어써요. 누르면 먼저 확인을 받아요.
- **메뉴와 팝업에서 숨기기:** 잘 안 쓰는 템플릿을 메뉴와 검색에서 감춰요.
- **+ 새 템플릿 / 복제 / 삭제 / ▲▼:** 내 템플릿을 만들고, 복제하고, 지우고, 순서를 바꿔요. 기본 템플릿은 지울 수 없고 숨길 수만 있어요.
- **오른쪽 가이드:** 커서가 있는 섹션에 맞는 작성 팁과 출처 링크를 보여줘요.

### 문구 탭
자주 쓰는 문장을 다섯 갈래(진행 방식, 범위, 보고·검증, 자료·맥락, 출력)로 모아 둬요. 추가, 수정, 삭제, 순서 바꾸기를 할 수 있어요. 문구에도 `{빈칸}`을 넣을 수 있어요.

### 단축키 · 설정 탭
- 모든 단축키를 한 표에서 보고 바꿔요.
- 템플릿 넣는 방식을 골라요(채우기 창 / 바로 붙여넣기).
- "로그인할 때 자동으로 실행"을 켜고 꺼요.
- 맥에서는 손쉬운 사용 권한 상태를 보여주고, 설정을 여는 버튼이 있어요.

## 9. 템플릿 문법

| 쓰는 법 | 뜻 |
|---|---|
| `## 목표` | 섹션 제목. 가이드 패널이 섹션별 팁을 보여줘요 |
| `{무엇을 만들지}` | 빈칸. 중괄호 안의 글은 무엇을 쓸지 알려주는 힌트예요 |
| `{{today}}` | 오늘 날짜로 바뀌어요 |
| `{{rulesFile}}` | 현재 모드의 규칙 파일 이름(CLAUDE.md 등)으로 바뀌어요 |

빈칸은 처음 연 템플릿 안의 위치로 추적해요. 그래서 로그나 JSON을 붙여넣다 생긴 `{}`는 빈칸으로 세지 않아요.

## 10. 데이터

설정과 수정한 템플릿·문구는 `data.json` 파일 하나에 저장돼요. 기본값과 다른 부분만 저장해서, 앱이 업데이트되어 기본 템플릿이 바뀌어도 고친 내용은 그대로 남아요.

- 맥: `~/Library/Application Support/dev.prompthelper.app/data.json`
- 윈도우: `%APPDATA%\dev.prompthelper.app\data.json`

파일이 깨져서 읽을 수 없으면 `data.corrupt-<시각>.json`으로 옮겨 두고 기본값으로 시작해요. 처음 상태로 돌리고 싶으면 앱을 종료한 뒤 이 파일을 지우면 돼요.

## 11. 알려진 한계

- 클립보드의 텍스트와 이미지는 되돌려 놓지만, 파일이나 서식 있는 텍스트 같은 다른 형식은 되돌리지 못해요.
- 다른 앱 안에서만 쓰는 단축키(예: Slack 안의 단축키)와 겹치는지는 알 수 없어요.
- 윈도우에서는 관리자 권한으로 실행된 앱에 붙여넣지 못해요.
- 윈도우용 코드는 아직 실행 검증을 하지 못했어요.
- 임시저장은 앱이 켜져 있는 동안만 남아요.
